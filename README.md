# KAELO DJ - Press Kit

Sitio web profesional de prensa para DJ KAELO, especializado en House, Tech House y Afro Tech.

## 🎵 Sobre KAELO

DJ con más de 13 años de experiencia en la industria electrónica. Ha actuado en venues destacados de Buenos Aires (Moscú, Creta, Bali, Groove) y es parte de **ABUNDANCE**, empresa de producción de eventos.

## 🛠️ Stack Tecnológico

- **Frontend**: Next.js 16 + React 19 + TypeScript
- **Styling**: Tailwind CSS 4
- **Deployment**: Vercel
- **Performance**: Optimizado para Web Core Vitals

## 🚀 Características

- Diseño responsive y moderno
- Experiencia de usuario fluida
- Integración con redes sociales
- SEO optimizado
- Carga rápida (Lighthouse A+)

## 📋 Secciones

- **Hero**: Presentación impactante
- **Bio**: Información profesional
- **Música**: Últimas producciones
- **Reels**: Contenido de video
- **Rider**: Requisitos técnicos
- **Contacto**: Formulario de reservas

## 🚀 Inicio Rápido

```bash
# Clonar repositorio
git clone https://github.com/djpinto2/presskit-kaelo.git
cd presskit-kaelo

# Instalar dependencias
npm install

# Desarrollo
npm run dev

# Build para producción
npm run build
npm start
```
